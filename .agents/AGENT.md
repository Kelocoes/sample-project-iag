# Guía para Agentes AI (Antigravity Agent Instructions)

Este repositorio contiene una aplicación completa de gestión con frontend en React Vite y backend en NestJS.

## 🛠️ Cómo ejecutar la aplicación ante una solicitud del usuario:

1. **Instalar Dependencias**:
   - En el backend: `cd backend && npm install`
   - En el frontend: `cd frontend && npm install`

2. **Compilar e Iniciar Servidores**:
   - Servidor Backend: `cd backend && npm run build && node dist/main.js` (Corre en `http://localhost:3000`)
   - Servidor Frontend: `cd frontend && npm run dev` (Corre en `http://localhost:5173`)

3. **Entregar Enlace al Usuario**:
   - Proporciona inmediatamente al usuario el enlace: **`http://localhost:5173`**
